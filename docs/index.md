# Alto Rst documentation

Alto Rst parses, renders, lints, converts, and safely edits
reStructuredText from PHP. These pages document its public PHP API.

## First steps

1. [Install Alto Rst](install.md).
2. [Parse and render a document](parse-and-render.md).

## Validate and migrate documentation

- [Lint RST](lint.md): run and configure the 20 recommended rules.
- [Convert documents](convert.md): convert individual documents or complete
  RST projects to Markdown, and Markdown back to RST.

## Maintain RST source

- [Fix, format, and edit](writing.md): plan minimal byte patches, preview
  diffs, and save with conflict detection.

## Understand the engine

- [Reference graph](references.md): resolve document and project-wide links,
  targets, footnotes, citations, and substitutions.
- [Security](security.md): understand trust boundaries, file access, raw
  HTML authority, and resource limits.
- [Extensions](extensions.md): executable profile extension contracts.
